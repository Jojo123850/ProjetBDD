#  Gestion d'événements

## Présentation

Ce projet consiste à concevoir et manipuler une base de données relationnelle pour une application de gestion d'événements.

L'objectif est de permettre la gestion des utilisateurs, des événements et des réservations à travers différentes requêtes SQL.

## Technologies utilisées

- **MySQL** : gestion de la base de données
- **SQL** : création, consultation et manipulation des données
- **phpMyAdmin** : administration de la base de données

## Structure de la base de données

La base de données `eventmanagement` contient quatre tables principales :

- `users` : informations des utilisateurs
- `roles` : rôles des utilisateurs (participant, organisateur, administrateur)
- `events` : informations des événements
- `reservations` : inscriptions des utilisateurs aux événements

## Fonctionnalités

- Créer un compte utilisateur
- Consulter les événements disponibles
- S'inscrire à un événement
- Consulter ses inscriptions
- Manipuler les données avec des requêtes SQL

## Fichiers du projet

- `ANDRIANIRINA_Giovanie_database.sql` : structure et données de la base
- `ANDRIANIRINA_Giovanie_queries.sql` : requêtes SQL correspondant aux cas d'utilisation
- `ANDRIANIRINA_Giovanie_documentation.pdf` : documentation du projet

## Installation

1. Créer une base de données MySQL nommée `eventmanagement`.
2. Importer le fichier `ANDRIANIRINA_Giovanie_database.sql` dans phpMyAdmin.
3. Consulter et exécuter les requêtes du fichier `ANDRIANIRINA_Giovanie_queries.sql`.

## Objectif pédagogique

Ce projet m'a permis de mettre en pratique la modélisation relationnelle, les clés primaires et étrangères, ainsi que la création et la manipulation de données avec SQL.
